## מצב מימוש (עודכן 2026-10-01)
- שלבים 1, 2, 4 הושלמו (יסודות, ליבה, מאגר מזון + חיפוש) ונשמרו ב-Git.
- **שינוי סדר:** כדי שהמשתמש יראה אפליקציה עובדת מוקדם, נבנו **שלבים 5–8 (חלקית) על Repository מקומי** (`src/data/local`, אחסון במכשיר) לפני שלב 3 (מסד נתונים). הממשקים (`src/data/types.ts`) זהים למה שיהיה מול Supabase, והמימוש המקומי אוכף את אותם כללים (idempotency, גרסאות, soft delete, חלון זמן, תקרות). החלפה לשרת = מימוש חדש לאותם ממשקים, בלי לשנות מסך.
- נבנו: הרשמה בארבעה שלבים + עדכון יעד, מסך "היום" (טבעת, גרף מסדרון, מאקרו, ארוחה הבאה, רשימת ארוחות), הוספה/עריכה/מחיקה/Undo, חיפוש מזון והזנה ידנית, מועדפים (בסיסי), התקדמות (גרף משקל + גרף שבועי + שקילה), הגדרות (ערכת נושא, יצוא JSON, מחיקת נתונים, מקורות).
- **נשאר:** שלב 3 (Supabase + התחברות + סנכרון + RLS), PWA (התקנה, Offline), יצוא CSV, מחיקת חשבון בשרת, שלב 10 (אבטחה ושחרור).
